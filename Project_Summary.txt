PROJECT SUMMARY — Trips & Tours (family travel journal website)
===============================================================
Last updated: 2026-09-03

PURPOSE
-------
A static website that keeps every trip the family has made in one place: a
"mind map" page per destination, our own photos and memories, a world map and an
India map of everywhere we have been, a quiz about the places, and a slideshow.
New places are added by asking Claude, who edits the data files.

LIVE SITE / HOSTING
-------------------
- URL: https://simonkayar.com/trips/
- Hosting: shared web hosting (Hostinger-style), plain FTP, port 21.
  Server path: /domains/simonkayar.com/public_html/trips
  (ftp.txt in the project root holds host/user/password — it is git-ignored and
  must never be committed or uploaded. The original note in ftp.txt mentioned
  public_html/sites/trips; the site was deployed to public_html/trips to match the
  URL simonkayar.com/trips.)
- Deploy: python tools/deploy_ftp.py   (uploads only changed files; --all forces
  everything; --dry-run previews; --list shows the remote folders). Excludes
  tools/, ftp.txt, design.txt, serve.bat, CLAUDE.md, the two summary files and
  photos/_originals/.

SOURCE CONTROL
--------------
- GitHub: https://github.com/simonkayar/trips  (branch main)
- .gitignore keeps ftp.txt, .venv, photos/_originals, .deploy-manifest.json out.
- Photos in photos/ and pictures in images/ are committed (they are public on the
  site anyway).

RUN LOCALLY
-----------
- Double-click serve.bat (python -m http.server 8765, opens the browser), or open
  index.html directly. The Leaflet maps need http:// for tiles.
- No build step, no Node. Python 3 only for helper scripts in tools/.
- Facts/ids are cross-checked with: python tools/validate_data.py

ARCHITECTURE (plain HTML/CSS/JS, data-driven)
---------------------------------------------
Pages: index.html (home: stats, collections, trips abroad), destinations.html
(search/filter, collections, grouped by state/country), place.html?id=<id> (the
mind-map page: hero picture, hub with flag/capital, At-a-glance, cartoon locator
map, History, Must see, Food, Culture, paged Fun facts, Tips, Our trip, photo
gallery), maps.html (Leaflet world + India), quiz.html, slideshow.html,
journal.html.
Shared JS: js/loader.js (creates window.TRIPS, loads every data file in order),
js/app.js (helpers, question generation, header/footer). Page scripts in js/.
Data (all in data/):
- places-international.js, places-karnataka.js, places-tamilnadu.js,
  places-kerala-ap-ts.js, places-others.js — 104 entries: 84 places + 20 hubs
  (countries/states). Schema documented in CLAUDE.md.
- questions-*.js — 488 hand-written quiz questions; app.js generates ~258 more
  from the data (state/country/tagline/"which is in X"/trip year questions).
- facts-*.js — extra fun facts merged into each place (TRIPS.extraFacts).
- collections.js — 14 themed collections (lists of place ids).
- trips.js — dated trips (international). notes.js — journal entries.
- photos.js — GENERATED by tools/scan_photos.py from photos/<id>/.
- images.js + images/<id>.jpg — GENERATED by tools/fetch_images.py (Wikipedia
  lead image per place with credit); flags in images/flags/. 102 of 104 have one
  (Thiruparankundram and Kufri have none).
- maps-svg.js — GENERATED by tools/build_maps.py from GeoJSON (world countries +
  India states) for the cartoon locator maps.
Browser storage: quiz "seen question" ids and journal quick notes live in
localStorage only.

KEY DECISIONS
-------------
- Pure static site with data in JS files (not JSON) so it also works from file://
  and needs no server-side code on the shared host.
- Lepakshi is filed under Andhra Pradesh (it is in AP, not Karnataka).
- The six abodes of Murugan are six separate entries; Pondicherry, Delhi and
  Chandigarh sit under UT/NCT hubs.
- Flag emoji do not render on Windows -> flag PNG images and ordinary emoji.
- Quiz hides the place name until the answer is shown (it gave away answers).
- Wikipedia pictures are shrunk to 1200px (py -3.10 tools/shrink_images.py);
  Wikimedia rate-limits, so fetch_images.py pauses/backs off — keep that.
- India state outlines are pre-2014 (no Telangana shape; Hyderabad gets a pin).
- Python: the machine's py -3.10 already has Pillow; no venv was created.

HOW TO ADD A PLACE (short version — details in CLAUDE.md)
--------------------------------------------------------
1. Add an entry to the right data/places-*.js (hub first if new state/country).
2. Add 4-8 questions to data/questions-*.js and 5-8 facts to data/facts-*.js.
3. Add the id to collections in data/collections.js if it fits.
4. Picture: add to TITLES in tools/fetch_images.py, run it for that id, shrink.
5. Photos: photos/<id>/ then python tools/scan_photos.py.
6. python tools/validate_data.py, then python tools/deploy_ftp.py, git commit/push.
